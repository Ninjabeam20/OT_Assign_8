# Tracks A and D: numerical methods and distributed optimization

All measurements come from executable NumPy implementations, five seeds (0–4) in full mode and seed 0 in quick mode. JSON includes raw per-seed measurements, traces, correctness checks and limitations. Runtime comparisons are illustrative, not controlled hardware studies. Individual public interfaces are `optlab.track_a.run(quick=False)` and `optlab.track_d.run(quick=False)`.

## A: objectives, algorithms and experimental controls

Linear regression minimizes `||Xw-y||²/(2n) + λ||w||²/2`. Independent Gaussian features give a strongly convex Hessian with probability one; duplicating one column gives a convex rank-deficient case. The reference is an independent least-squares solve. Every optimizer starts at zero on identical data. Full mode uses 600 updates, but the output also counts observation-gradient evaluations: 600 single-sample SGD updates are **not** the same work as 600 full-batch updates. Timing therefore cannot establish an equal-budget winner.

GD uses the full gradient; SGD samples one observation; minibatch samples eight without replacement each update. Momentum maintains velocity `v=.9v-ηg`; NAG evaluates the gradient at `w+.9v`. Adagrad accumulates squared gradients; RMSprop uses a .9 exponential average. Adam uses .9/.999 moments and both bias corrections. All adaptive denominators include numerical epsilon. Newton solves the damped Hessian system; Gauss–Newton solves a damped `JᵀJ` system. They coincide for linear residuals. A separate nonlinear exponential fit `a exp(bx)` demonstrates the difference: Newton includes residual-weighted second derivatives, Gauss–Newton omits them, and both use positive-definiteness damping and Armijo backtracking.

The first-order convergence reference: an L-smooth convex objective with step size at most 1/L has the standard O(1/k) GD objective bound; adding strong convexity yields geometric convergence. These assumptions do not cover arbitrary neural networks. Nonconvex experiments minimize `(x²-1)²+y²+τx`. At τ=0, the origin has Hessian eigenvalues -4 and 2 and is an exact stationary saddle; noiseless GD initialized there stays there. Perturbed gradients can escape. With τ=.15, the two wells have unequal local minima, so initialization matters. The experiment reports objectives, gradient norms and minimum curvature rather than claiming global convergence.

A separate training/validation/test split selects learning rate among .001, .01, .05, .2, .8 and 2 using validation error. Test error is evaluated after selection. Label-noise experiments compare GD, SGD and minibatches at noise standard deviations 0, .5 and 2. The synthetic tanh network has manually implemented backpropagation. Its derivative routine is shared by GD and Adam: backpropagation is a derivative computation, not an optimizer. L2 penalties 0/.01 expose changes in norm and held-out MSE; regularization does not automatically improve every seed.

For Bernoulli logistic regression, the expected Fisher equals `Xᵀ diag(p(1-p)) X/n`, which is also the negative-log-likelihood Hessian. The empirical Fisher uses outer products of observed per-example gradients and is reported separately because it need not equal that Hessian. We compare diagonal and rank-three approximations by relative Frobenius error, solve a damped natural-gradient system and validate an implicit Hessian-vector product against a dense matrix. Approximation storage counts exclude temporary arrays. Dense construction is used for validation only; the HVP formula itself needs no dense Hessian.

## D: submodularity and parallel execution

Maximum coverage is monotone submodular: adding a set to a larger collection cannot add more uncovered elements. The implementation exhaustively checks diminishing returns for all subset pairs of eight candidate sets, compares greedy to exhaustive cardinality-k optima and checks the `1-1/e` guarantee. Random instances happened to be easy, so an explicit fixture records greedy coverage 5 versus optimum 6. The exact algorithm is exponential and intentionally limited to tiny instances. The cardinality-specific bound is `1-(1-1/k)^k`.

The scheduler executes actual CPU-bound arithmetic in separate spawned processes, using two workers when available. Static scheduling assigns contiguous chunks; dynamic scheduling uses one-task chunks from a process pool; explicit work stealing uses worker-local LIFO queues, peer FIFO steals and a synchronized manager lock. Heavy jobs are clustered to create static imbalance. Every result is compared with the serial list, checking task IDs and values so lost and duplicated work are detectable. Steal and lock-acquisition counts are recorded. The global manager lock is deliberately simple, and its IPC cost limits scalability. The benchmark includes process spawn, serialization, synchronization and shutdown in timings; tiny workloads can be slower in parallel.

Contiguous versus transposed strided reductions provide a separate measured locality experiment with matching checksums. Data parallelism splits input rows; model parallelism splits output columns; a two-stage process pipeline forwards eight microbatches through tanh and a second matrix multiplication. Each decomposition is checked against serial NumPy output. These are inference demonstrations, not distributed training. Payload-byte estimates omit Python serialization framing. BLAS may internally use threads, so thread environment and machine metadata should accompany reproducibility claims.

Speedup is `T_serial/T_parallel`, efficiency is speedup divided by worker count. Amdahl predicts `1/(s+(1-s)/p)` for fixed-size work; Gustafson predicts `p-s(p-1)` for scaled work. Values at explicitly assumed serial fractions .05/.2/.5 are predictions, not empirical scaling curves. Inverting Amdahl on measured timings yields an effective serial fraction; values above one indicate overhead incompatible with the ideal model and are retained rather than clipped.

FedAvg trains four non-IID clients of different sizes. Features and label offsets vary by client. Every round starts local models from the common server weights and aggregates them weighted by sample count. Local steps 1/5/20 and rounds 5/20 vary computation and communication. The centralized baseline performs the same total full-data gradient work. One local step is algebraically equivalent to a centralized update and is checked numerically. Communication counts both broadcast and returned model arrays. Clients are simulated sequentially; this is an algorithmic experiment, not a network throughput benchmark.

The two-task linear model shares six weights and has separate task biases. Targets intentionally oppose each other. Equal weighting minimizes the mean task objective. For two gradients, MGDA exactly minimizes the squared norm of their convex combination by projecting its scalar coefficient to [0,1]. GradNorm updates positive weights using shared-gradient norms and relative loss progress (alpha 1.5), treats target norms as constants during the weight update and renormalizes weights to sum two. Per-task train/test loss and weight traces expose tradeoffs; no claim is made that one method wins every objective. MGDA uses the full parameter gradient, including task-specific bias entries.

## Validation and actual encountered failures

`tests/test_numerical.py` checks known least-squares solutions for all ten optimizers, finite-difference backprop, HVP equality, a nonlinear fit, exact coverage, conflicting/aligned MGDA gradients, one-step FedAvg equivalence, and real process outputs. Initial dependency installation was still running when the first test invocation failed with `No module named pytest`; after dependencies became available the suite ran normally. Missing implementation assertions were observed before implementation. Two additional tests were explicitly observed failing for the absent nonlinear fit and adversarial coverage fixture, then passed after their implementation.

An initial implementation choice only compared Newton and Gauss–Newton on linear residuals, where they are identical; review exposed its explanatory weakness. The added nonlinear fit addresses that limitation. Initial random maximum-coverage instances all produced optimal greedy solutions; the explicit 5/6 fixture now prevents the misleading impression that greedy is always exact. These are genuine development issues, not fabricated AI mistake stories.

An intentionally aggressive learning rate of 2 produced enormous validation losses (roughly 10^60–10^93 in the saved run), while validation selected .05 or .2. Fixed-step RMSprop and SGD retained nonzero objective gaps; Adagrad progressed slowly under its shared step-size setting. These outcomes are retained, not hidden by retuning each optimizer after seeing results. Tiny multiprocessing jobs often lose to serial execution; the saved speedups are measured and can vary on rerun. They do not prove work stealing or parallel computation is generally ineffective.

In the five-seed verification, maximum manual-backprop finite-difference error was approximately 2.75e-10, maximum HVP discrepancy 2.78e-16, parallel decomposition error zero and one-step FedAvg discrepancy 8.33e-17.
